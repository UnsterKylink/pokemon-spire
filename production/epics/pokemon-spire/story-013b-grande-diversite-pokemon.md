## Acceptance Criteria

*From the player's request (2026-10-24, « une grande diversité de Pokémon ») and `design/game-brief.md` étape 2, scoped to this story:*

- [x] Plusieurs centaines de Pokémon jouables en données, toutes générations (1 à 9) : au minimum les lignées d'évolution complètes de Pokémon communs de tous les types, avec nom français, types, PV, comportement ennemi, sprite PokéAPI stocké dans `assets/sprites/pokemon/` et 1–2 cartes d'attaque cohérentes avec leurs types.
- [x] Chaque type (18) a au moins 15 Pokémon, de sorte que les zones, les arènes et le Conseil 4 tirent dans des pools variés ; le type Ténèbres devient possible en arène.
- [x] Les Pokémon sauvages des zones, les élites, les porteurs de cartes de récompense et les propositions de départ tirent dans ce grand roster (pools et poids en données), sans casser la cohérence de type.
- [x] Les nouveaux Pokémon ont leurs données d'évolution (forme suivante) quand elle existe.
- [x] Les données restent validées au chargement (types, sprites, cartes) ; le temps de chargement reste raisonnable (< 3 s).
