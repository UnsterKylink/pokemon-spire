**Date:** 2026-10-21 · **Engine:** Godot 4.6.3-stable (Linux, cloud session, Xvfb 1280x720, gl_compatibility)
**How captured:** `xvfb-run -a -s "-screen 0 1280x720x24" godot --path . --windowed --resolution 1280x720 -s res://tools/qa/battle_walkthrough.gd -- <this folder> story-007`. The 2nd argument `story-007` is a new walkthrough filter. It runs only `_champion_shots`, so no other story's shots land in this folder.

The victory part uses run seed 4242 with Salamèche. Before the run starts, `qa_set_money(187)` and `qa_give_item("restes")` are applied. The walkthrough then walks the **real act map** up to the Champion: 15 rooms, with fights won by real card clicks after `qa_set_enemy_hp(1)`. The defeat part starts from the real "Nouvelle partie" button. It wins the floor-1 room, then loses a fight with `qa_lose_battle()`. That helper keeps the player at 1 HP with no block and ends turns, so the enemies' real attacks deal the KO. That fight is a debug `trio_vol` encounter, because no floor-2 wild room was reachable on that map. The new runs after a restart use a random seed, so the starter proposals in 05/06 vary from one capture to the next.
